[#theorem-fundamental-arithmetic]
[THEOREM]
.Theorem: The Fundamental Theorem of Arithmetic in CGA
====
Every discrete positive integer measurement count \( n > 1 \) in \( \mathbb { Z } ^ + \) decomposes uniquely into a product of prime measurement counts \( M ( n ) = n \cdot \mathbf { 1 } = \prod _ { i = 1 } ^ k p _ i ^ { a _ i } \cdot \mathbf { 1 } \) in the Grade-0 scalar subalgebra of CGA, up to the order of prime factors.

_Proof:_

. _Discrete Integer Measurement Representation:_ Represent integer count \( n \) as the Grade-0 CGA scalar multivector \( M ( n ) = n \cdot \mathbf { 1 } \), scaling a unit conformal boundary dilator \( E _ 0 = e _ \odot \wedge e _ \infty \) by factor \( n \) (Postulates 0 & 2).

. _Existence of Prime Factorization:_ If \( n \) is prime, the product representation is immediate with \( k = 1 , a _ 1 = 1 \). If \( n \) is composite, it factors into non-trivial discrete measurement steps \( n = a b \) with \( 1 < a , b < n \), corresponding to successive conformal dilations by \( a \) and \( b \). By finite induction on integer step counts, every integer decomposes into a finite product of prime counts \( \prod _ { i = 1 } ^ k p _ i ^ { a _ i } \).

. _Bézout Coprimality and Euclid's Lemma:_ For any prime step count \( p \) not dividing integer \( a \), the greatest common divisor \( \gcd ( p , a ) = 1 \) is constructively obtained via the Euclidean division chain in a finite number of steps, yielding integers \( u , v \in \mathbb { Z } \) satisfying Bézout's identity \( u p + v a = 1 \). Multiplying by \( b \) gives \( u p b + v a b = b \); hence if \( p \mid a b \), then \( p \) divides both terms on the left and therefore \( p \mid b \).

. _Uniqueness by Finite Step Induction:_ Suppose \( n = \prod _ { i = 1 } ^ k p _ i = \prod _ { j = 1 } ^ m q _ j \). Since \( p _ 1 \mid \prod _ { j = 1 } ^ m q _ j \), repeated application of Euclid's Lemma forces \( p _ 1 \mid q _ j \), hence \( p _ 1 = q _ j \), for some \( j \). Canceling \( p _ 1 \) in the Grade-0 scalar ring and applying induction on \( n / p _ 1 \) establishes that \( k = m \) and \( p _ i = q _ i \) for all factors up to permutation.

. _Tautological Conclusion:_ Integer measurement step counts possess a unique prime factor decomposition in Grade-0 CGA scalar arithmetic. \( \square \)

Subtracting \( d _ 0 \) and dividing by \( b \) yields \( d _ 1 = c _ 1 \) , and by finite induction, \( d _ k = c _ k \) for all \( k = 0 , \dots , M \) .

In this chapter, statistical inference and hypothesis testing are reformulated as exact operational gauging procedures on finite discrete measurement data, establishing optimal parameter estimation and information criteria.

=== The Maximum Likelihood Estimation Theorem

[#theorem-mle-uniqueness]
[THEOREM]
.Theorem: Uniqueness of Maximum Likelihood Estimates
====
For discrete measurement counts on grid \( \mathcal { G } _ N \), the Jaynesian MaxEnt likelihood estimator \( \hat { \theta } _ { \text { ML } } \) is uniquely determined and achieves minimal variance on finite operational samples.

_Proof:_

. _Operational Log-Likelihood:_ Define the grade-0 log-likelihood function \( L ( \theta \mid \{ x _ i \} ) = \sum _ { i = 1 } ^ k \ln P ( x _ i \mid \theta ) \).

. _Strict Concavity:_ Evaluate the second MSRA derivative \( D _ { \mathcal { I } } ^ 2 L ( \theta ) \). Under Jaynesian MaxEnt priors, \( D _ { \mathcal { I } } ^ 2 L ( \theta ) = - I _ { \mathcal { I } } ( \theta ) \), where \( I _ { \mathcal { I } } ( \theta ) > 0 \) is the positive-definite Fisher information matrix.

. _Uniqueness of Stationarity:_ Since \( D _ { \mathcal { I } } ^ 2 L ( \theta ) \) is negative-definite, the stationary equation \( D _ { \mathcal { I } } L ( \hat { \theta } ) = 0 \) possesses a unique solution \( \hat { \theta } _ { \text { ML } } \).

. _Tautological Conclusion:_ Maximum Likelihood estimation yields a unique, optimal parameter estimate for any finite data set on \( \mathcal { G } _ N \). \( \square \)
====

=== The Iris Minimum Entropy Information Criterion (IMEIC)

[#theorem-imeic-bound]
[THEOREM]
.Theorem: Exact Model Complexity Bound in CGA
====
The optimal multivector model complexity for discrete data on grid \( \mathcal { G } _ N \) is specified by the Iris Minimum Entropy Information Criterion:
\[ \text { IMEIC } ( M ) = - 2 L ( \hat { \theta } _ { \text { ML } } ) + 2 K _ { \text { grade } } ( M ) \]

where \( K _ { \text { grade } } ( M ) \) is the exact multivector blade degree of freedom in 6D CGA.

_Proof:_

. _Multivector Grade Complexity:_ Model space in 6D CGA over canonical generators \( \{ e _ 1 , e _ 2 , e _ 3 , e _ 4 , e _ \odot , e _ \infty \} \) is spanned by grades 0 through 6, with total dimension \( \sum _ { k = 0 } ^ { 6 } \binom { 6 } { k } = 64 \). A model \( M \) uses \( K _ { \text { grade } } ( M ) \) independent blade generators.

. _Jaynesian Information Loss:_ The expected relative entropy (Kullback-Leibler divergence) between the true data generator and model candidate \( M \) expands as:
\[ \mathbb { E } _ { \text { MaxEnt } } \left [ D _ { \text { KL } } ( P _ { \text { true } } \parallel P _ M ) \right ] = - L ( \hat { \theta } _ { \text { ML } } ) + K _ { \text { grade } } ( M ) + \mathcal { O } ( N ^ { - 1 } ) \]

. _Exact Non-Asymptotic Form:_ Multiplying by 2 and projecting via Main Scale Projection \( ( \downarrow ) \) yields the exact criterion \( \text { IMEIC } ( M ) \).

. _Tautological Conclusion:_ Model selection minimizes information loss without over-fitting CGA multivector blade dimensions. \( \square \)
====

=== The Finite-Sample Cramer-Rao Inequality

[#theorem-cramer-rao-bound]
[THEOREM]
.Theorem: Finite-Sample Vernier Variance Lower Bound
====
The variance of any unbiased operational estimator \( T ( X ) \) for parameter \( \theta \) on discrete grid \( \mathcal { G } _ N \) satisfies:
\[ \text { Var } _ { \mathcal { I } } ( T ( X ) ) \ge \frac { 1 } { I _ { \mathcal { I } } ( \theta ) } \]

where \( I _ { \mathcal { I } } ( \theta ) \) is the scalar Fisher information bound.

_Proof:_

. _Unbiased Expectation Condition:_ Let \( \mathbb { E } _ { \text { MaxEnt } } [ T ( X ) ] = \theta \). Differentiating both sides with respect to \( \theta \) using MSRA derivative \( D _ { \mathcal { I } } \) yields:
\[ \sum _ { x \in \mathcal { G } _ N } T ( x ) D _ { \mathcal { I } } P ( x \mid \theta ) = 1 \]

. _Score Operator Identity:_ Rewrite \( D _ { \mathcal { I } } P ( x \mid \theta ) = P ( x \mid \theta ) D _ { \mathcal { I } } \ln P ( x \mid \theta ) + \mathcal { O } ( \delta ) \).

. _Cauchy-Schwarz Multivector Inequality:_ Applying the Iris inner product inequality under Main Scale Projection \( ( \downarrow ) \) to \( ( T ( X ) - \theta ) \) and \( D _ { \mathcal { I } } \ln P ( X \mid \theta ) \) gives:
\[ \mathbb { E } \left [ ( T ( X ) - \theta ) ^ { 2 } \right ] \cdot \mathbb { E } \left [ ( D _ { \mathcal { I } } \ln P ( X \mid \theta ) ) ^ { 2 } \right ] \ge 1 \]

. _Fisher Information Identification:_ Recognizing \( I _ { \mathcal { I } } ( \theta ) = \mathbb { E } \left [ ( D _ { \mathcal { I } } \ln P ( X \mid \theta ) ) ^ { 2 } \right ] \) yields the exact lower bound \( \text { Var } _ { \mathcal { I } } ( T ( X ) ) \ge I _ { \mathcal { I } } ( \theta ) ^ { - 1 } \).

. _Tautological Conclusion:_ No unbiased operational estimator on \( \mathcal { G } _ N \) can exceed the precision bound imposed by the Fisher information. \( \square \)
====

== Applications to Conventional Statistics

In this chapter, classical methods of conventional statistics—such as hypothesis testing via \( p \)-values, confidence intervals, analysis of variance (ANOVA), and linear regression estimation—are mapped into exact operational gauge operations within the discrete Iris framework. We demonstrate how conventional statistical formulas arise as finite-window projections of CGA multivector distributions under Jaynesian Maximum Entropy constraints, eliminating reliance on infinite uncountable distributions while preserving operational sampling bounds.

=== Operational Hypothesis Testing on Discrete Grids

[#theorem-operational-hypothesis-testing]
[THEOREM]
.Theorem: Operational Exactness of Discrete Hypothesis Testing
====
Let \( H _ 0 \) and \( H _ 1 \) be operational hypotheses defined on discrete partition grid \( \mathcal { G } _ N \). The conventional likelihood ratio test statistic \( \Lambda ( X ) = \frac { P ( X \mid H _ 0 ) } { P ( X \mid H _ 1 ) } \) acts as a scalar grade-0 projection \( Q _ { \text { gauge } } ( X ) \in \text { CGA } \), wherein conventional \( p \)-values represent exact discrete tail-counting sampling fractions under Jaynesian MaxEnt state assignments without uncountable integral approximations.

_Proof:_

. _Discrete Tail-Counting Measure:_ On finite grid \( \mathcal { G } _ N \), the operational probability of observing a sample \( X \) at least as extreme as \( x _ 0 \) under \( H _ 0 \) is the finite sum \( p _ { \text { tail } } = \sum _ { x \in \mathcal { G } _ N : \Lambda ( x ) \le \Lambda ( x _ 0 ) } P ( x \mid H _ 0 ) \).

. _Exact Vernier Bounding:_ Because \( \mathcal { G } _ N \) contains a finite step count \( N \), \( p _ { \text { tail } } \) is an exact rational step fraction in \( \mathbb { R } _ { \mathcal { I } } \), avoiding uncountable normal or \( t \)-distribution approximations.

. _Multivector Likelihood Ratio:_ Embedding \( P ( X \mid H _ k ) \) in CGA over \( \{ e _ 1 , e _ 2 , e _ 3 , e _ 4 , e _ \odot , e _ \infty \} \) via Main Scale Projection \( ( \downarrow ) \) yields \( \Lambda ( X ) \) as the grade-0 scalar blade of the Jaynesian likelihood ratio.

. _Tautological Conclusion:_ Conventional hypothesis testing is an exact finite-window tail-counting operation on discrete partition state spaces. \( \square \)
====

=== Analysis of Variance (ANOVA) in Multivector Space

[#theorem-discrete-anova-decomposition]
[THEOREM]
.Theorem: Operational Variance Decomposition in Finite Multivector ANOVA
====
For a finite discrete data matrix partitioned into \( K \) operational sampling groups on grid \( \mathcal { G } _ N \), the total multivector sum of squares \( SS _ { \text { total } } \) satisfies the exact identity \( SS _ { \text { total } } = SS _ { \text { between } } + SS _ { \text { within } } \) in CGA, guaranteeing that conventional Analysis of Variance (ANOVA) \( F \)-tests are finite projections of Jaynesian partition energy conservation.

_Proof:_

. _Group Partition Energy:_ Let \( x _ { ij } \in \mathcal { G } _ N \) denote the \( j \)-th discrete measurement step count in group \( i \). The deviation identity reads \( ( x _ { ij } - \bar { x } ) = ( x _ { ij } - \bar { x } _ i ) + ( \bar { x } _ i - \bar { x } ) \).

. _Orthogonality of Discrete Cross-Terms:_ Summing the squared differences over finite grid points \( i \in \{ 1 , \dots , K \} \) and \( j \in \{ 1 , \dots , n _ i \} \) causes the cross-term \( 2 \sum _ { i , j } ( x _ { ij } - \bar { x } _ i ) ( \bar { x } _ i - \bar { x } ) \) to vanish identically by definition of the group Vernier mean \( \bar { x } _ i \).

. _CGA Orthogonal Partition Conservation:_ Taking the grade-0 squared norm in CGA yields \( SS _ { \text { total } } = SS _ { \text { between } } + SS _ { \text { within } } \).

. _Tautological Conclusion:_ ANOVA variance decomposition is a structural identity of discrete orthogonal decomposition on finite measurement grids. \( \square \)
====

=== Multivector Linear Regression and Gauss-Markov Efficiency

[#theorem-discrete-regression-gauss-markov]
[THEOREM]
.Theorem: Discrete Gauss-Markov Theorem for Multivector Linear Regression
====
Given a linear discrete observation model \( Y = X \beta + \epsilon \) on finite grid \( \mathcal { G } _ N \) with zero-mean, uncorrelated discrete noise \( \epsilon \), the Ordinary Least Squares (OLS) estimator \( \hat { \beta } = ( X ^ T X ) ^ { - 1 } X ^ T Y \) is the unique Minimum Variance Linear Unbiased Estimator (BLUE) within CGA under Jaynesian finite-sample constraints.

_Proof:_

. _Linear Unbiased Class:_ Consider any alternative linear estimator \( \tilde { \beta } = C Y \). The unbiased condition \( \mathbb { E } _ { \text { MaxEnt } } [ \tilde { \beta } ] = \beta \) requires \( C X = \mathbf { I } \).

. _Variance Decomposition:_ Express \( C = ( X ^ T X ) ^ { - 1 } X ^ T + D \), where \( D X = \mathbf { 0 } \). The covariance operator evaluates to \( \text { Var } _ { \mathcal { I } } ( \tilde { \beta } ) = \sigma ^ 2 ( X ^ T X ) ^ { - 1 } + \sigma ^ 2 D D ^ T \).

. _Positive Definiteness:_ Since \( D D ^ T \) is a non-negative definite operator in the CGA Euclidean parameter subspace, \( \text { Var } _ { \mathcal { I } } ( \tilde { \beta } ) \ge \text { Var } _ { \mathcal { I } } ( \hat { \beta } ) \), with equality if and only if \( D = \mathbf { 0 } \).

. _Tautological Conclusion:_ The discrete OLS estimator uniquely minimizes sampling variance across all linear unbiased estimators on \( \mathcal { G } _ N \). \( \square \)
====
