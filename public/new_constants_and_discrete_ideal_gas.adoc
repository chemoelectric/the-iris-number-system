Let \( \rho _ { N } = \frac{N}{V} \) be the number density of gas molecules in the container.

In an isotropic gas on the discrete grid \( \mathcal{G}_N \), velocity distributions are symmetric under spatial reflections: exactly half of the molecules with speed \( |v _ { x }| \) move in the positive \( +x \) direction toward the wall, and half move in the negative \( -x \) direction away from the wall.

Therefore, the number of collisions with the wall of area \( A \) during duration \( \tau \) by molecules with velocity component \( v _ { x } \) is:
\[
\Delta N _ { c }(v _ { x }) = \frac{1}{2} \rho _ { N } \Delta V _ { \text{cyl }} = \frac{1}{2} \left( \frac{N}{V} \right) A v _ { x } \tau
\]

*Step 3: Total Momentum Transferred to the Wall*

The total momentum \( \Delta P _ { \text{total }} \) transferred to area \( A \) during duration \( \tau \) is obtained by summing the momentum transfers of all arriving molecules:
\[
\Delta P _ { \text{total }} = \sum _ { v _ { x  } > 0} \Delta N _ { c }(v _ { x }) \cdot \Delta p _ { x }
\]
Substitute the expressions for \( \Delta N _ { c }(v _ { x }) \) and \( \Delta p _ { x } \):
\[
\Delta P _ { \text{total }} = \sum _ { v _ { x  } > 0} \left[ \frac{1}{2} \left( \frac{N}{V} \right) A v _ { x } \tau \right] \cdot \left[ 2 (\Delta m) v _ { x } \right]
\]
Multiply the numerical constants:
\[
\frac{1}{2} \times 2 = 1
\]
Therefore:
\[
\Delta P _ { \text{total }} = \left( \frac{N}{V} \right) A \tau (\Delta m) \sum _ { v _ { x  } > 0} v _ { x } ^  { 2 }
\]
Averaging over the entire ensemble of \( N \) molecules, because \( v _ { x } ^  { 2 } \) is identical for positive and negative values, the sum over \( v _ { x } > 0 \) equals the ensemble mean:
\[
\sum _ { v _ { x  } > 0} v _ { x } ^  { 2 } = \frac{1}{2} N \langle v _ { x } ^  { 2 } \rangle \cdot 2 = N \langle v _ { x } ^  { 2 } \rangle
\]
Thus, the total momentum transfer simplifies to:
\[
\Delta P _ { \text{total }} = \left( \frac{N}{V} \right) A \tau (\Delta m) \langle v _ { x } ^  { 2 } \rangle
\]

*Step 4: Extension of Mechanical Pressure*

Mechanical pressure \( P \) is defined extensionally as the time-averaged normal force per unit area:
\[
P \equiv \frac{F _ { \text{normal }}}{A} = \frac{1}{A} \left( \frac{\Delta P _ { \text{total }}}{\tau} \right)
\]
Substitute the expression for \( \Delta P _ { \text{total }} \):
\[
P = \frac{1}{A \tau} \left[ \left( \frac{N}{V} \right) A \tau (\Delta m) \langle v _ { x } ^  { 2 } \rangle \right]
\]
Cancel \( A \) and \( \tau \) in the numerator and denominator:
\[
P = \left( \frac{N}{V} \right) (\Delta m) \langle v _ { x } ^  { 2 } \rangle
\]
Recall that the total mass of the gas is \( M = N (\Delta m) \), and the mass density is \( \rho = \frac{M}{V} = \frac{N (\Delta m)}{V} \). Therefore:
\[
P = \rho \langle v _ { x } ^  { 2 } \rangle
\]

*Step 5: Spatial Isotropy on the Grid \( \mathcal{G}_N \)*

The magnitude of the molecular velocity vector is:
\[
v ^  { 2 } = v _ { x } ^  { 2 } + v _ { y } ^  { 2 } + v _ { z } ^  { 2 }
\]
Taking the ensemble expectation value on both sides:
\[
\langle v ^  { 2 } \rangle = \langle v _ { x } ^  { 2 } \rangle + \langle v _ { y } ^  { 2 } \rangle + \langle v _ { z } ^  { 2 } \rangle
\]
Because the discrete grid \( \mathcal{G}_N \) has orthogonal symmetry in three spatial dimensions, there is no preferred coordinate axis:
\[
\langle v _ { x } ^  { 2 } \rangle = \langle v _ { y } ^  { 2 } \rangle = \langle v _ { z } ^  { 2 } \rangle
\]
Substitute this equality into the sum:
\[
\langle v ^  { 2 } \rangle = \langle v _ { x } ^  { 2 } \rangle + \langle v _ { x } ^  { 2 } \rangle + \langle v _ { x } ^  { 2 } \rangle = 3 \langle v _ { x } ^  { 2 } \rangle
\]
Divide both sides by 3:
\[
\langle v _ { x } ^  { 2 } \rangle = \frac{1}{3} \langle v ^  { 2 } \rangle
\]
Substitute \( \langle v _ { x } ^  { 2 } \rangle = \frac{1}{3} \langle v ^  { 2 } \rangle \) into the pressure equation:
\[
P = \frac{1}{3} \rho \langle v ^  { 2 } \rangle = \frac{1}{3} \left( \frac{N (\Delta m)}{V} \right) \langle v ^  { 2 } \rangle
\]

*Step 6: Relation to Kinetic Energy and the Equation of State*

Rewrite the right-hand side by factoring out \( \frac{2}{3} \):
\[
P = \frac{2}{3} \left( \frac{N}{V} \right) \left[ \frac{1}{2} (\Delta m) \langle v ^  { 2 } \rangle \right]
\]
The term in brackets is the mean translational kinetic energy per molecule:
\[
\langle E _ { k } \rangle \equiv \frac{1}{2} (\Delta m) \langle v ^  { 2 } \rangle
\]
Therefore:
\[
P = \frac{2}{3} \left( \frac{N}{V} \right) \langle E _ { k } \rangle
\]
Multiply both sides of the equation by volume \( V \):
\[
P V = \frac{2}{3} N \langle E _ { k } \rangle
\]
This is the _exact fundamental equation of state_ for the discrete Ideal Gas. Not a single continuum approximation was made.

=== Extension of Temperature and the SI Constants \( k _ { B } \) and \( R \)

In physical metrology, the kelvin unit of thermodynamic temperature \( T \) is calibrated by partitioning mean translational kinetic energy equally among the three spatial translational degrees of freedom:
\[
\frac{1}{2} k _ { B } T \equiv \frac{1}{3} \langle E _ { k } \rangle = \frac{1}{2} (\Delta m) \langle v _ { x } ^  { 2 } \rangle
\]
Multiply both sides of this definition by 3:
\[
\frac{3}{2} k _ { B } T = \langle E _ { k } \rangle
\]
Now substitute this exact physical definition into the equation of state \( P V = \frac{2}{3} N \langle E _ { k } \rangle \):
\[
P V = \frac{2}{3} N \left( \frac{3}{2} k _ { B } T \right)
\]
The fractions cancel completely:
\[
\frac{2}{3} \times \frac{3}{2} = 1
\]
Therefore:
\[
P V = N k _ { B } T
\]
For a sample of gas containing \( n \) moles, where Avogadro's constant \( N _ { A } \) defines the molar entity count (\( N = n N _ { A } \)):
\[
P V = (n N _ { A }) k _ { B } T = n (N _ { A } k _ { B }) T
\]
Define the molar gas constant:
\[
R \equiv N_A k_B
\]
Substituting \( R \) yields the familiar molar equation of state:
\[
P V = n R T
\]

=== Nature of the Thermodynamic Constants

This unbroken derivation establishes the true physical nature of \( k _ { B } \) and \( R \):
1. _The Boltzmann Constant \( k _ { B } \)_ is not a mysterious universal property of nature; it is a _conversion factor_ that translates the human macroscopic scale of temperature (kelvins, historically tied to the thermal expansion of mercury and ice-water phase changes) into mechanical kinetic energy (joules):
   \[
   k _ { B } = \frac{2 \langle E _ { k } \rangle}{3 T} \approx 1.380649 \times 10 ^  { -23 } \text{ J/K}
   \]
2. _The Molar Gas Constant \( R \)_ is the macroscopic molar momentum flux constant:
   \[
   R = N_A k_B \approx 8.3144626 \text{ J/(mol}\cdot\text{K)}
   \]
3. The Ideal Gas Law is not an empirical curve-fit; it is an exact theorem of discrete momentum conservation and contact dynamics on the resolution grid \( \mathcal{G}_N \).
