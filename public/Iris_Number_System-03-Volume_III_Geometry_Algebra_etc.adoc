== Constructive 2D Euclidean Geometric Algebra Cl(2,0) and Planar Rotors

This section establishes 2D Euclidean Geometric Algebra \( Cl ( 2 , 0 ) \) embedded directly as a sub-algebra of \( Cl ( 4 , 1 , 1 ) \) spanned by spatial basis vectors \( e _ 1 , e _ 2 \) with \( e _ 1 ^ 2 = e _ 2 ^ 2 = \mathbf { 1 } _ { Cl } \) and \( e _ 1 e _ 2 = - e _ 2 e _ 1 \).

[#theorem-2d-euclidean-rotor]
[THEOREM]
.Theorem: Constructive 2D Euclidean Rotor Equivalence Theorem
====
In 2D Euclidean Geometric Algebra \( Cl ( 2 , 0 ) \subset Cl ( 4 , 1 , 1 ) \), the pseudoscalar bivector \( I _ 2 = e _ 1 e _ 2 \) satisfies \( I _ 2 ^ 2 = - \mathbf { 1 } _ { Cl } \). *Proof:*

. **Pseudoscalar Square**: \( I _ 2 ^ 2 = ( e _ 1 e _ 2 ) ( e _ 1 e _ 2 ) = - e _ 1 e _ 1 e _ 2 e _ 2 = - \mathbf { 1 } _ { Cl } \).

. **Rotor Reversal Norm**: The reverse rotor is \( \tilde { R } = \cos ( \theta / 2 ) \mathbf { 1 } _ { Cl } + \sin ( \theta / 2 ) I _ 2 \). Thus \( R \tilde { R } = \cos ^ 2 ( \theta / 2 ) \mathbf { 1 } _ { Cl } + \sin ^ 2 ( \theta / 2 ) \mathbf { 1 } _ { Cl } = \mathbf { 1 } _ { Cl } \).

. **Length Invariance**: Evaluating the square of transformed vector \( v ' = R v \tilde { R } \):
\[ ( v ' ) ^ 2 = ( R v \tilde { R } ) ( R v \tilde { R } ) = R v ( \tilde { R } R ) v \tilde { R } = R v ^ 2 \tilde { R } = v ^ 2 R \tilde { R } = v ^ 2 \mathbf { 1 } _ { Cl } \]
Since \( v ^ 2 = ( x ^ 2 + y ^ 2 ) \mathbf { 1 } _ { Cl } \), length preservation holds strictly on rational grid steps. \( \square \)

== Constructive 4D Homogeneous Geometric Algebra: Null and Ordinary-Magnitude Basis Formulations

This section establishes 4D Homogeneous Projective Geometric Algebra under dual basis representations within \( Cl ( 4 , 1 , 1 ) \): both with a degenerate null origin basis \( e _ 0 \) (\( e _ 0 ^ 2 = 0 \), Projective GA) and with an ordinary-magnitude basis \( e _ 4 \) (\( e _ 4 ^ 2 = \mathbf { 1 } _ { Cl } \), Euclidean 4D projective embedding).

[#theorem-4d-homogeneous-motor]
[THEOREM]
.Theorem: Constructive 4D Homogeneous Projective Duality and Dual Basis Motor Invariance Theorem
====
In 4D Homogeneous Geometric Algebra, 3D affine points, lines, and planes are represented projectively. The system admits two equivalent constructive formulations for 3D rigid motions (rotations and translations) on discrete grid \( \mathcal { G } _ N \):

Rigid motions are mediated by dual-quaternionic motors \( M = T R \), where translator \( T = \mathbf { 1 } _ { Cl } - \frac { 1 } { 2 } t e _ 0 \) is exact due to nilpotency \( ( t e _ 0 ) ^ 2 = 0 \).

2. **Ordinary-Magnitude Basis Formulation \( Cl ( 4 , 0 ) \)**: Spanned by spatial basis \( \{ e _ 1 , e _ 2 , e _ 3 \} \) and non-degenerate 4th basis \( e _ 4 \) (\( e _ 4 ^ 2 = \mathbf { 1 } _ { Cl } \)). \[ T P \tilde { T } = \left ( \mathbf { 1 } _ { Cl } - \frac { 1 } { 2 } t e _ 0 \right ) P \left ( \mathbf { 1 } _ { Cl } + \frac { 1 } { 2 } t e _ 0 \right ) = P + \frac { 1 } { 2 } ( P t e _ 0 - t e _ 0 P ) = P + t e _ 0 \]

. **Equivalence and Motor Composition**: In both formulations, motor composition \( M = T R \) preserves grade structure and rational grid norms \( M \tilde { M } = \mathbf { 1 } _ { Cl } \), proving constructive equivalence of degenerate null and ordinary-magnitude 4D homogeneous geometric algebras. \( \square \)

== Symmetric s-Power Basis and Geometric Polynomial Representation

This section constructs the symmetric \( s \)-power basis (Sánchez-Reyes, 1997) for parametric polynomial curves on discrete rational grids \( \mathcal { G } _ N \), establishing a direct correspondence between algebraic polynomial coefficients and geometric curve skeletons.

[#theorem-spower-geometric-representation]
[THEOREM]
.Theorem: Geometric s-Power Polynomial Representation and Vanishing Curvature Identity
====
Every planar quadratic Bézier curve \( P ( t ) \) with control points \( P _ 0 , P _ 1 , P _ 2 \in \mathcal { G } _ N \) for parameter \( t \in [ 0 , 1 ] \) admits a unique decomposition in the symmetric \( s \)-power basis:
\[ P ( t ) = ( 1 - t ) P _ 0 + t P _ 2 + ( 1 - t ) t P _ 1 ^ { \Delta } \]
where the skeleton endpoints are \( P _ 0 \) and \( P _ 2 \), and the deviation vector is \( P _ 1 ^ { \Delta } = 2 P _ 1 - P _ 0 - P _ 2 \). The curve is evaluated symmetrically via:
\[ P ( t ) = \left\{ \begin{array}{ll} P _ 0 + t \left ( ( P _ 2 - P _ 0 ) + ( 1 - t ) P _ 1 ^ { \Delta } \right ) , & t \le \frac { 1 } { 2 } \\ P _ 2 + ( 1 - t ) \left ( ( P _ 0 - P _ 2 ) + t P _ 1 ^ { \Delta } \right ) , & t > \frac { 1 } { 2 } \end{array} \right. \]
The deviation vector \( P _ 1 ^ { \Delta } = \mathbf { 0 } \) if and only if \( P ( t ) \) degenerates to an affine linear segment \( ( 1 - t ) P _ 0 + t P _ 2 \).

*Proof:*

. **Bernstein to s-Power Transformation**: In standard quadratic Bernstein basis, \( P ( t ) = ( 1 - t ) ^ 2 P _ 0 + 2 ( 1 - t ) t P _ 1 + t ^ 2 P _ 2 \). Expanding \( ( 1 - t ) ^ 2 = ( 1 - t ) - ( 1 - t ) t \) and \( t ^ 2 = t - ( 1 - t ) t \):
\[ P ( t ) = ( 1 - t ) P _ 0 - ( 1 - t ) t P _ 0 + 2 ( 1 - t ) t P _ 1 + t P _ 2 - ( 1 - t ) t P _ 2 = ( 1 - t ) P _ 0 + t P _ 2 + ( 1 - t ) t ( 2 P _ 1 - P _ 0 - P _ 2 ) \]
Setting \( P _ 1 ^ { \Delta } = 2 P _ 1 - P _ 0 - P _ 2 \), the representation is exact.

. **Symmetric Piecewise Evaluation**: Factoring \( ( 1 - t ) t P _ 1 ^ { \Delta } \) into \( t ( ( P _ 2 - P _ 0 ) + ( 1 - t ) P _ 1 ^ { \Delta } ) \) for \( t \le 1 / 2 \) and around \( P _ 2 \) for \( t > 1 / 2 \) eliminates loss of precision near domain boundaries on rational grid \( \mathcal { G } _ N \).

. **Vanishing Deviation**: If \( P _ 1 ^ { \Delta } = \mathbf { 0 } \), then \( P _ 1 = \frac { 1 } { 2 } ( P _ 0 + P _ 2 ) \), reducing \( P ( t ) \) to the affine linear segment \( ( 1 - t ) P _ 0 + t P _ 2 \). Thus algebra and geometry coincide. \( \square \)
====

== Skeleton Affine Projection and Optimal Fat-Line Bounding

This section establishes coordinate transformations mapping curve skeletons to standard orientation and derives the optimal parallel fat-line enclosure in the \( s \)-power basis.

[#theorem-optimal-fat-line-width]
[THEOREM]
.Theorem: Optimal s-Power Fat-Line Bounding and Skeleton Projection
====
Let \( P ( t ) \) be a clipper curve with non-coincident endpoints \( P _ 0 , P _ 2 \). The affine projection \( \mathbf { T } _ { \text { skel } } \) mapping \( P _ 0 \mapsto ( 0 , 0 ) \) and \( P _ 2 \mapsto ( 1 , 0 ) \) transforms \( P ( t ) \) into projected curve \( P ' ( t ) = ( t + ( 1 - t ) t d _ x , ( 1 - t ) t d _ y ) \), where \( ( d _ x , d _ y ) = \mathbf { T } _ { \text { skel } } ( P _ 1 ^ { \Delta } ) \).

The exact minimum parallel fat-line bounds enclosing \( P ' ( t ) \) for all \( t \in [ 0 , 1 ] \) are given by \( y = d _ { \text { min } } \) and \( y = d _ { \text { max } } \), where:
\[ d _ { \text { min } } = \min \left ( 0 , \frac { d _ y } { 4 } \right ) - \epsilon _ { \text { pad } } , \quad d _ { \text { max } } = \max \left ( 0 , \frac { d _ y } { 4 } \right ) + \epsilon _ { \text { pad } } \]
The central coefficient \( d _ y / 4 \) is exactly four times the signed optimal fat-line width, providing a tighter bound than control polygon convex hulls without generating Bernstein control points.

*Proof:*

. **Skeleton Coordinate Matrix**: The affine transformation matrix mapping segment \( P _ 0 P _ 2 \) to \( ( 0 , 0 ) \to ( 1 , 0 ) \) is constructed by defining vector \( \mathbf { v } = P _ 2 - P _ 0 = ( \Delta x , \Delta y ) \). With norm squared \( L ^ 2 = \Delta x ^ 2 + \Delta y ^ 2 \neq 0 \), the transformation maps point \( Q \) to \( Q ' \):
\[ x ' = \frac { \Delta x ( x _ Q - x _ 0 ) + \Delta y ( y _ Q - y _ 0 ) } { L ^ 2 } , \quad y ' = \frac { - \Delta y ( x _ Q - x _ 0 ) + \Delta x ( y _ Q - y _ 0 ) } { L ^ 2 } \]
Under this projection, \( P _ 0 ' = ( 0 , 0 ) \) and \( P _ 2 ' = ( 1 , 0 ) \).

. **Y-Coordinate Extreme Value**: In projected coordinates, the distance function to the skeleton line is simply the y-coordinate \( y ' ( t ) = ( 1 - t ) t d _ y \). Differentiation yields \( \frac { d y ' } { d t } = ( 1 - 2 t ) d _ y \). Setting the derivative to zero gives the unique critical point at \( t = 1 / 2 \).

. **Optimal Bound Value**: Evaluating at \( t = 1 / 2 \) gives \( y ' ( 1 / 2 ) = \left ( 1 - \frac { 1 } { 2 } \right ) \frac { 1 } { 2 } d _ y = \frac { d _ y } { 4 } \). Since \( ( 1 - t ) t \ge 0 \) for all \( t \in [ 0 , 1 ] \), the y-coordinate is bounded strictly between \( 0 \) and \( d _ y / 4 \). Adding numerical padding \( \epsilon _ { \text { pad } } \) ensures strict containment on finite rational grid \( \mathcal { G } _ N \). \( \square \)
====

== Algebraic Intersection via Quadratic Boundary Crossings and Clipping Plans

This section formulates the exact quadratic solution for fat-line boundary crossings, interval reparameterization, and clipping plan classification.

[#theorem-spower-clipping-convergence]
[THEOREM]
.Theorem: s-Power Quadratic Clipping Convergence and Root Isolation
====
Let \( Q ( t ) \) be a clippehend curve projected into the skeleton coordinate frame of clipper \( P ( t ) \), with projected y-polynomial \( Q _ y ' ( t ) = ( 1 - t ) Q _ { 0 , y } ' + t Q _ { 2 , y } ' + ( 1 - t ) t { Q _ { 1 , y } ' } ^ { \Delta } \). The intersection parameters \( t \) at fat-line boundary \( y = y _ { \text { bound } } \) are the exact real roots of the quadratic equation:
\[ A t ^ 2 + B t + C = 0 \]
where \( A = - { Q _ { 1 , y } ' } ^ { \Delta } \), \( B = { Q _ { 1 , y } ' } ^ { \Delta } + Q _ { 2 , y } ' - Q _ { 0 , y } ' \), and \( C = Q _ { 0 , y } ' - y _ { \text { bound } } \).

The iterative clipping plan \( t \mapsto ( 1 - t ) t _ 0 + t t _ 1 \) isolates all curve intersection points on rational grid \( \mathcal { G } _ N \) in a finite number of steps \( M \le \lceil \log _ 2 ( 1 / \epsilon ) \rceil \).

*Proof:*

. **Algebraic Boundary Equation**: Setting \( Q _ y ' ( t ) = y _ { \text { bound } } \):
\[ ( 1 - t ) Q _ { 0 , y } ' + t Q _ { 2 , y } ' + ( 1 - t ) t { Q _ { 1 , y } ' } ^ { \Delta } = y _ { \text { bound } } \]
Expanding \( ( 1 - t ) t { Q _ { 1 , y } ' } ^ { \Delta } = ( t - t ^ 2 ) { Q _ { 1 , y } ' } ^ { \Delta } \) and grouping by powers of \( t \):
\[ - { Q _ { 1 , y } ' } ^ { \Delta } t ^ 2 + \left ( { Q _ { 1 , y } ' } ^ { \Delta } + Q _ { 2 , y } ' - Q _ { 0 , y } ' \right ) t + \left ( Q _ { 0 , y } ' - y _ { \text { bound } } \right ) = 0 \]

. **Quadratic Formula Solution**: Real roots in \( [ 0 , 1 ] \) are extracted via the stable quadratic formula. If there are two crossings \( t _ { \text { lft } } \le t _ { \text { rgt } } \), the clippehend parameter domain is restricted to sub-interval \( [ t _ { \text { lft } } , t _ { \text { rgt } } ] \).

. **Interval Reparameterization**: A curve portion on parameter sub-interval \( [ t _ 0 , t _ 1 ] \) is re-expressed in \( s \)-power basis with new endpoints \( P _ 0 ^ { \text { new } } = P ( t _ 0 ) \), \( P _ 2 ^ { \text { new } } = P ( t _ 1 ) \), and scaled deviation vector \( P _ 1 ^ { \Delta , \text { new } } = ( t _ 1 - t _ 0 ) ^ 2 P _ 1 ^ { \Delta } \). The factor \( ( t _ 1 - t _ 0 ) ^ 2 \) guarantees quadratic convergence of the deviation vector to zero, forcing the sub-curve toward an affine linear segment. \( \square \)
====

\[ x ' = \frac { 2 ( x - ( - 1 ) ) + 0 ( y - 0 ) } { 4 } = \frac { x + 1 } { 2 } \]

   - Y-deviation coefficient: \( d _ y = 10 \).
   - Maximum Y-coordinate: \( d _ y / 4 = 10 / 4 = 2 . 5 \).
   - Fat-line bounds: \( d _ { \text { min } } = 0 - \epsilon _ { \text { pad } } \), \( d _ { \text { max } } = 2 . 5 + \epsilon _ { \text { pad } } \).
   - The clipper curve lies entirely within the horizontal band \( y ' \in [ 0 , 2 . 5 ] \) in skeleton coordinates.

.Example Problem 3: Combination of s-Power Bézier Clipping and Flatness Testing for Near-Parallel Curves

*Problem*: Explain how the \( s \)-power basis simplifies flatness testing for two curves running nearly parallel, and derive the threshold condition under which clipping converts to exact affine line-segment intersection.

*Solution*:

1. **s-Power Flatness Criterion**:
   - In Bernstein basis, testing flatness requires computing control polygon distances to control legs. In \( s \)-power basis, flatness depends exclusively on the norm of the deviation vector \( P _ 1 ^ { \Delta } \).
   - A curve \( P ( t ) \) is \( \epsilon \)-flat if \( \| P _ 1 ^ { \Delta } \| _ { \mathcal { I } } \le 4 \epsilon \).
   - When sub-interval reparameterization reduces interval length to \( \Delta t = t _ 1 - t _ 0 \), the new deviation vector scales as \( P _ 1 ^ { \Delta , \text { new } } = ( \Delta t ) ^ 2 P _ 1 ^ { \Delta } \).

3. **Closed-Form Affine Intersection**:
   - Replacing both flattened curves by segments \( L _ P ( t _ p ) = ( 1 - t _ p ) P _ 0 + t _ p P _ 2 \) and \( L _ Q ( t _ q ) = ( 1 - t _ q ) Q _ 0 + t _ q Q _ 2 \):
\[ ( 1 - t _ p ) P _ 0 + t _ p P _ 2 = ( 1 - t _ q ) Q _ 0 + t _ q Q _ 2 \]
   - Solved in a single matrix inversion step without iteration, guaranteeing termination and exactness on rational grid \( \mathcal { G } _ N \).

== Trivial Degree Elevation and Geometric Piecewise Degree Reduction

This section establishes the algebraic simplicity of degree elevation in the symmetric \( s \)-power basis and formulates geometric degree reduction, constructing a piecewise lower-degree polynomial bounded by quadratic error convergence.

[#theorem-spower-degree-elevation-reduction]
[THEOREM]
.Theorem: s-Power Trivial Degree Elevation and Geometric Degree Reduction
====
Let \( P ( t ) = ( 1 - t ) P _ 0 + t P _ 2 + ( 1 - t ) t P _ 1 ^ { \Delta } \) be a quadratic curve in the symmetric \( s \)-power basis on rational grid \( \mathcal { G } _ N \).

1. **Trivial Degree Elevation**: Re-expressing \( P ( t ) \) as a degree-3 (cubic) curve in the \( s \)-power basis:
\[ P ( t ) = ( 1 - t ) Q _ 0 + t Q _ 3 + ( 1 - t ) ^ 2 t Q _ 1 ^ { \Delta } + ( 1 - t ) t ^ 2 Q _ 2 ^ { \Delta } \]
is executed trivially by inheriting the lower-degree deviation vector directly into both cubic deviation positions without modifying endpoints:
\[ Q _ 0 = P _ 0 , \quad Q _ 3 = P _ 2 , \quad Q _ 1 ^ { \Delta } = P _ 1 ^ { \Delta } , \quad Q _ 2 ^ { \Delta } = P _ 1 ^ { \Delta } \]

2. **Geometric Degree Reduction**: Reducing \( P ( t ) \) to an affine linear segment (degree 1) by setting \( P _ 1 ^ { \Delta } \mapsto \mathbf { 0 } \) incurs a maximum geometric deviation bounded by:
\[ E _ 1 = \max _ { t \in [ 0 , 1 ] } \| P ( t ) - L ( t ) \| _ { \mathcal { I } } = \frac { 1 } { 4 } \| P _ 1 ^ { \Delta } \| _ { \mathcal { I } } \]
When domain \( [ 0 , 1 ] \) is partitioned into \( K \) uniform sub-intervals of length \( \Delta t = 1 / K \), setting sub-interval deviation vectors \( P _ 1 ^ { \Delta , ( i ) } = ( \Delta t ) ^ 2 P _ 1 ^ { \Delta } \mapsto \mathbf { 0 } \) yields a \( C ^ 0 \) piecewise linear curve whose maximum error to \( P ( t ) \) converges quadratically as:
\[ E _ K = \frac { \| P _ 1 ^ { \Delta } \| _ { \mathcal { I } } } { 4 K ^ 2 } \]

*Proof:*

. **Degree Elevation Identity**: Substituting \( 1 = ( 1 - t ) + t \) into the quadratic deviation term yields:
\[ ( 1 - t ) t P _ 1 ^ { \Delta } = ( 1 - t ) t [ ( 1 - t ) + t ] P _ 1 ^ { \Delta } = ( 1 - t ) ^ 2 t P _ 1 ^ { \Delta } + ( 1 - t ) t ^ 2 P _ 1 ^ { \Delta } \]
Matching coefficients with the cubic \( s \)-power expansion \( ( 1 - t ) Q _ 0 + t Q _ 3 + ( 1 - t ) ^ 2 t Q _ 1 ^ { \Delta } + ( 1 - t ) t ^ 2 Q _ 2 ^ { \Delta } \) directly verifies \( Q _ 0 = P _ 0 \), \( Q _ 3 = P _ 2 \), \( Q _ 1 ^ { \Delta } = P _ 1 ^ { \Delta } \), and \( Q _ 2 ^ { \Delta } = P _ 1 ^ { \Delta } \).

. **Geometric Degree Reduction Bound**: The deviation from the linear backbone \( L ( t ) = ( 1 - t ) P _ 0 + t P _ 2 \) is \( d ( t ) = ( 1 - t ) t P _ 1 ^ { \Delta } \). Since the scalar function \( f ( t ) = ( 1 - t ) t \) achieves its absolute maximum at \( t = 1 / 2 \) with value \( f ( 1 / 2 ) = 1 / 4 \), the maximum geometric error over \( [ 0 , 1 ] \) is exactly \( \frac { 1 } { 4 } \| P _ 1 ^ { \Delta } \| _ { \mathcal { I } } \).

. **Subdivision Error Scaling**: Under reparameterization on sub-interval \( [ t _ i , t _ { i + 1 } ] \) with length \( \Delta t = 1 / K \), the deviation vector scales as \( P _ 1 ^ { \Delta , ( i ) } = ( \Delta t ) ^ 2 P _ 1 ^ { \Delta } \). Replacing each quadratic sub-arc with its linear backbone segment gives a piecewise linear approximation with maximal sub-interval error \( \frac { 1 } { 4 } \| P _ 1 ^ { \Delta , ( i ) } \| = \frac { \| P _ 1 ^ { \Delta } \| } { 4 K ^ 2 } \). \( \square \)
====

[#example-spower-degree-reduction]
[EXAMPLE]
.Example Problem 4: Trivial Degree Elevation and Geometric Piecewise Degree Reduction
====
*Problem*: Given the quadratic Bézier curve \( P ( t ) \) with control points \( P _ 0 = ( 0 , 0 ) \), \( P _ 1 = ( 2 , 8 ) \), \( P _ 2 = ( 4 , 0 ) \):
1. Elevate its degree trivially to cubic in the \( s \)-power basis.
2. Calculate the maximum error of reducing its degree directly to a single linear segment.
3. Determine the number of uniform sub-intervals \( K \) required for geometric degree reduction to yield a piecewise linear curve within tolerance \( \epsilon = 0 . 0 5 \).

*Solution*:

1. **s-Power Representation and Elevation**:
   - Deviation vector: \( P _ 1 ^ { \Delta } = 2 P _ 1 - P _ 0 - P _ 2 = 2 ( 2 , 8 ) - ( 0 , 0 ) - ( 4 , 0 ) = ( 4 , 16 ) - ( 4 , 0 ) = ( 0 , 16 ) \).
   - Quadratic representation: \( P ( t ) = ( 1 - t ) ( 0 , 0 ) + t ( 4 , 0 ) + ( 1 - t ) t ( 0 , 16 ) \).
   - Elevated cubic representation: \( Q _ 0 = ( 0 , 0 ) \), \( Q _ 3 = ( 4 , 0 ) \), \( Q _ 1 ^ { \Delta } = ( 0 , 16 ) \), \( Q _ 2 ^ { \Delta } = ( 0 , 16 ) \):
\[ P ( t ) = ( 1 - t ) ( 0 , 0 ) + t ( 4 , 0 ) + ( 1 - t ) ^ 2 t ( 0 , 16 ) + ( 1 - t ) t ^ 2 ( 0 , 16 ) \]

2. **Single-Segment Linear Degree Reduction Error**:
   - Deviation vector norm: \( \| P _ 1 ^ { \Delta } \| = \sqrt { 0 ^ 2 + 16 ^ 2 } = 16 \).
   - Single linear segment approximation: \( L ( t ) = ( 1 - t ) ( 0 , 0 ) + t ( 4 , 0 ) = ( 4 t , 0 ) \).
   - Maximum geometric error: \( E _ 1 = \frac { 1 } { 4 } \| P _ 1 ^ { \Delta } \| = \frac { 1 6 } { 4 } = 4 . 0 \).

3. **Subdivision for Target Tolerance**:
   - Require \( E _ K = \frac { \| P _ 1 ^ { \Delta } \| } { 4 K ^ 2 } \le \epsilon \implies \frac { 1 6 } { 4 K ^ 2 } \le 0 . 0 5 \implies \frac { 4 } { K ^ 2 } \le 0 . 0 5 \implies K ^ 2 \ge 8 0 \).
   - Taking ceiling: \( K = \lceil \sqrt { 8 0 } \rceil = 9 \).
   - With \( K = 9 \) sub-intervals (\( \Delta t = 1 / 9 \)), the scaled sub-interval deviation vector norm is \( \| P _ 1 ^ { \Delta , ( i ) } \| = \frac { 1 6 } { 8 1 } \approx 0 . 1 9 75 \).
   - The piecewise linear backbone curve achieves maximum geometric error \( E _ 9 = \frac { 1 6 } { 4 \times 8 1 } = \frac { 4 } { 8 1 } \approx 0 . 0 4 9 4 < 0 . 0 5 \), producing a lightweight piecewise polynomial extraordinarily close to the original curve.
====

= Multivector Representation Theory and Character Orthogonality

In this chapter, representation theory is constructed for finite matrix and multivector groups acting on Clifford modules in \( Cl ( 4 , 1 , 1 ) \). Complete reducibility, character orthogonality, and Schur's Lemma are formally proved.

== Discrete Multivector Spinor Modules and Irreducible Representations

[#theorem-iris-irreducible-representation-decomposition]
[THEOREM]
.Theorem: Irreducible Multivector Representation Decomposition Theorem
====
Every finite group representation \( \rho : G \to \text { Aut } ( Cl ( 4 , 1 , 1 ) ) \) over the rational grid field decomposes uniquely into a direct sum of irreducible multivector representation modules \( V = \bigoplus _ { j = 1 } ^ r W _ j ^ { \oplus m _ j } \).
